# Retratos tipo carnet

Subir aquí los retratos individuales del roster del Instituto Xavier.

- Mantener una imagen por integrante.
- Usar nombres de archivo claros y estables, preferentemente el alias del personaje (por ejemplo: `nexus.jpg`, `oratoris.jpg`).
- No reemplazar las cartas oficiales: estos archivos son retratos independientes para las tarjetas del roster.
- Formatos recomendados: JPG, PNG o WebP.
